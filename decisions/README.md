# Decision Memory

Every material decision made for CoreGrid Scholar is recorded here so future
agents and engineers can reconstruct *why* the system is the way it is
without guessing.

- `architecture-decisions.md` - structural and boundary decisions
- `technology-decisions.md` - framework, tooling, and dependency decisions
- `security-decisions.md` - security and trust decisions

Format: lightweight ADR entries (Context, Decision, Consequences). Append,
never rewrite history.
