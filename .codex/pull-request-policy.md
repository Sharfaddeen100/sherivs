# Pull Request Policy

- All changes flow through pull requests on the `coregrid-scholar-migration`
  branch until the mainline strategy is ratified.
- Every PR must state the architecture phase it belongs to.
- Every PR must pass build + unit tests + relevant e2e tests.
- Every PR must update the affected documentation (`DECISIONS.md`, `PROGRESS.md`, `docs/`).
- A second reviewer must approve before merge; no self-merge for
  non-trivial changes.
