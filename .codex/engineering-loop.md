# Engineering Loop

The engineering loop for every task:

1. **Orient** - read architecture, constitution, decisions, progress.
2. **Scope** - confirm the task belongs to an approved phase.
3. **Implement** - smallest change that satisfies the scope.
4. **Test** - unit + e2e + build, per `testing-policy.md`.
5. **Document** - update decisions, progress, and affected docs.
6. **Ship** - open a pull request per `pull-request-policy.md`.

Never skip steps 4-6. "It works on my machine" is not a definition of done.
