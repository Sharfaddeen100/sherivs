# Progress Memory

The single source of truth for what has happened, what is happening, what is
blocked, and what comes next on CoreGrid Scholar.

- `current-state.md` - snapshot of the platform right now
- `completed.md` - finished work
- `in-progress.md` - active work
- `blocked.md` - blockers
- `next-tasks.md` - prioritized next steps

Update these files whenever work changes state.
