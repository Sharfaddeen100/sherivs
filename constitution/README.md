# CoreGrid Scholar Constitution

The constitution is the binding policy layer of the CoreGrid Scholar
platform. It outranks convenience, deadlines, and individual judgment.

Documents:

- `core-principles.md` - identity and non-negotiable principles
- `engineering-policy.md` - how engineering work is performed
- `security-policy.md` - security requirements and responsibilities
- `ai-agent-policy.md` - rules for AI systems operating on the platform
- `data-governance-policy.md` - data ownership, retention, and privacy
- `development-rules.md` - day-to-day development rules

These files currently contain placeholders. Each policy must be ratified
before it is treated as binding.
