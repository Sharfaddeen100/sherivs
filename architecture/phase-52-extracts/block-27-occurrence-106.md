BLOCK 27 — PERSONAL VS ORGANIZATIONAL DATA

CoreGrid should have an explicit separation:

PERSONAL REALITY
       ║
       ║ governed boundary
       ║
ORGANIZATION REALITY

An organization should not automatically see a person's personal reality.

Likewise, a user's personal AI should not automatically access organizational confidential information.

Cross-context access requires:

Identity
+
Membership
+
Permission
+
Purpose
+
Policy
+
Consent where applicable
